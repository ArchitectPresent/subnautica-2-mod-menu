## 🧩 About

**Subnautica 2 helpers** is a curated list of Subnautica 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, depth meter, oxygen alert
- **Quality-of-Life Helpers** — inventory sorter, crafting queue notes, beacon manager, map markers
- **Research Notes** — biome layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Exploration Helpers
- Resource Tracker — highlight nearby materials
- Depth Meter — on-screen depth and pressure display
- Oxygen Alert — configurable warning thresholds
- Beacon Manager — save and teleport between beacons (single-player)

### 🎒 Inventory & Crafting
- Auto Sorter — organize inventory by category
- Craft Queue — queue multiple recipes
- Quick Stack — deposit items to nearby containers
- Item Scanner — identify unknown resources

### 🗺️ Map & Navigation
- Mini Map — toggleable minimap with custom markers
- Biome Overlay — show current biome boundaries
- Waypoint System — set and navigate to custom points
